
# 👨‍💼 HR Analytics Dashboard

## Project Overview

This HR Analytics Dashboard was developed using Microsoft Power BI to analyze workforce data and provide meaningful business insights for HR decision-making.

## Tools Used

- Power BI
- Power Query
- DAX

## Dashboard Features

- Employee Overview
- Department Analysis
- Salary Analysis
- Performance Rating
- Attendance Analysis
- Job Satisfaction
- Attrition Analysis

## Skills Demonstrated

- Data Cleaning
- Data Modeling
- DAX Measures
- KPI Development
- Interactive Dashboard Design
- Business Insight Generation
